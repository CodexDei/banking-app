# Banking-app

**Legacy Core Banking Integration Simulator**

Banking-app es un proyecto de integración bancaria desarrollado con Java y Spring Boot, cuyo objetivo es simular la comunicación entre aplicaciones digitales modernas y un sistema core bancario legado basado en tecnologías tradicionales como COBOL.

El sistema implementará APIs REST, transformación de mensajes legados a JSON, separación de responsabilidades, manejo de errores, seguridad y pruebas automatizadas.

## Objetivo inicial

Desarrollar una API REST capaz de consultar el saldo de una cuenta bancaria mediante un adaptador que se comunique con un simulador de sistema legado.

## Tecnologías

- Java 17
- Spring Boot
- Maven
- APIs REST y JSON
- JUnit y Mockito
- Git y GitHub

## Estado del proyecto

En desarrollo. Primera etapa: definición y configuración del proyecto.

## Alcance

Proyecto educativo y de portafolio. No utiliza sistemas, información ni infraestructura real de entidades financieras.
